3D Gaussian Splatting（浏览器）
当前：
压缩 ply（~5MB）：原版 point_cloud.ply 无 sh 块时 GaussianSplats3D 会解析失败 → 黑屏。运行 python examples/web_teleop/patch_compressed_ply_for_gs3d.py … 或 download_gs_assets_for_web.py 生成 *.gs3d.ply（仅头补丁，体积极小）。
标准 ply（~55MB）：*.webgs.ply 由脚本用 gaussian_renderer 解码导出；服务端 gzip 后约 ~15MB。
*.gs3d.ply 需最新服务端（否则 gzip 分块无 Content-Length，进度无百分比）；解析 ~35 万高斯时底部状态会出现「解析/构建」，可能需十余秒。
